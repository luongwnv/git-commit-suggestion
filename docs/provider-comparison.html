Provider Comparison

Authoritative state of each provider class in src/providers/. Keep this in sync with config/providers.yml.

id Class Schema Default model Free? BYOK? Auth Notes
mistral OpenAICompatibleProvider OpenAI /chat/completions mistral-small-latest Yes Yes Bearer Free tier ~1 req/s. Default provider.
openai OpenAICompatibleProvider OpenAI /chat/completions gpt-4o-mini No Yes Bearer BYOK only; no official free API tier.
anthropic AnthropicProvider Anthropic /messages claude-haiku-4-5-20251001 No Yes x-api-key Different schema; system field is top-level; max_tokens required.
groq OpenAICompatibleProvider OpenAI /chat/completions llama-3.1-8b-instant Yes Yes Bearer Free tier with 60 req/min on most models.
ollama OllamaProvider Ollama /api/chat llama3.1:8b Yes No None Local; base URL overridable; stream=false; format=json.
g4f G4FProvider OpenAI /chat/completions gpt-3.5-turbo Unofficial No None Opt-in (enableUnofficialProviders); rotates endpoints; falls back to Mistral.

When to use what

  • You just want it to work, free, with a key: Mistral. Default.
  • You want speed and free: Groq with llama-3.1-8b-instant.
  • You want offline / privacy: Ollama with a local model. Slower first call.
  • You have a paid OpenAI/Anthropic key already: use that — best quality.
  • You explicitly accept the risks of unofficial reverse proxies: g4f, but Mistral fallback should still be configured.
